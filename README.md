## 高中语文作文 Wiki

一个基于 **LLM Wiki 模式**的高中语文作文知识库，同时也是一个 Obsidian vault。用户负责提供原始资料（范文、素材），LLM 负责结构化整理、建立双向链接、维护索引——共同构建一个可检索、可关联的作文素材网络。

### 项目特点

- **LLM 驱动维护**：所有 wiki 页面的创建、更新、索引同步均由 LLM 完成，用户只需提供原材料
- **双向链接网络**：基于 Obsidian `[[双链]]` 语法，素材、范文、主题之间形成密集的关联网络
- **原子化设计**：每个素材一个独立页面，便于按需组合引用
- **来源可信**：范文全文原样搬运，写作指导仅允许来自原始资料，AI 补充内容明确标注 `【AI】`

### 文件结构

```
EssaySystem/
├── raw/                        # 原始资料（LLM 只读不改）
│   └── archive/                # 已处理归档的资料
├── wiki/                       # LLM 维护的 wiki
│   ├── material/               # 素材页面（人物 / 事件 / 道理）
│   │   └── index.md            # 素材详细索引（按子类分组）
│   ├── essay/                  # 范文页面
│   ├── topic/                  # 主题页面
│   ├── issues/                 # 素材矛盾冲突问题报告
│   ├── index.md                # 主索引（主题 + 范文 + 素材一览）
│   └── log.md                  # 操作日志（append-only）
├── templates/                  # 页面模板
│   ├── material-template.md    # 素材模板
│   ├── essay-template.md       # 范文模板
│   └── topic-template.md       # 主题模板
├── scripts/                    # 辅助脚本
│   └── validate_frontmatter.py # frontmatter 校验（纯标准库，零依赖）
├── .claude/                    # Claude Code 配置
│   └── skills/                 # LLM 工作流定义
│       ├── ingest/SKILL.md     # 导入工作流
│       ├── query/SKILL.md      # 查询工作流
│       └── lint/SKILL.md       # 健康检查工作流
└── CLAUDE.md                   # Claude Code 项目指令
```

#### 内容类型

Wiki 中有三种页面类型，对应三个目录：

| 类型 | 目录 | 说明 | 命名规则 |
|------|------|------|----------|
| **素材** | `wiki/material/` | 人物事迹、事件、道理论据 | 本名，如 `苏轼.md` |
| **范文** | `wiki/essay/` | 完整作文原文 + 结构分析 | `来源-作文标题.md` |
| **主题** | `wiki/topic/` | 作文主题的综合分析 | 四字或六字短语，如 `家国情怀.md` |

素材按子类型进一步分为：

- **人物** — 历史人物、文学家、思想家等（如 `鲁迅.md`、`陶渊明.md`）
- **事件** — 历史事件、社会现象等（如 `信息茧房.md`、`高山流水.md`）
- **道理** — 哲学观点、理论概念等（如 `各美其美.md`、`T型人才.md`）

### Skills（工作流技能）

项目定义了三个核心 skill，分别对应三种操作：

#### `/ingest` — 导入素材或范文

将 `raw/` 下的原始资料结构化导入 wiki。

**支持两种内容：**

1. **范文** — 完整搬运原文，提取结构分析，识别关联素材
2. **素材** — 原子化拆分，建立人物/事件/道理页面，补充使用示例

**核心流程：**

1. 读取 `raw/` 下的新文件，识别内容类型
2. 读取对应模板（`templates/`）
3. 按模板结构创建 wiki 页面，建立双向链接
4. 更新索引（`wiki/index.md` 和 `wiki/material/index.md`）
5. 移动原始文件到 `raw/archive/`
6. 追加操作日志到 `wiki/log.md`

**冲突检测：** 若导入素材与已有素材存在事实性矛盾，自动生成矛盾冲突报告到 `wiki/issues/`。

#### `/query` — 查询 wiki 内容

综合索引和页面回答作文相关问题。

**流程：**

1. 读取主索引，概览全部内容
2. 根据问题缩小范围（素材索引 / 主题页 / 范文页）
3. 读取目标页面，提取相关信息
4. 综合回答，附带 `[[wikilinks]]` 引用

**使用场景：**

- "有哪些关于坚持的素材？"
- "帮我找一篇写信息茧房的范文"
- "这个主题下可以用哪些素材？"

#### `/lint` — 健康检查

对 wiki 进行全面的质量检查。

**检查项目：**

1. **Frontmatter 校验** — 通过 `scripts/validate_frontmatter.py` 检查元数据完整性
2. **死链扫描** — 使用 Obsidian CLI 检测无效链接
3. **孤立笔记** — 发现没有任何链接指向的页面
4. **双向链接** — 验证 A→B 和 B→A 链接的完整性
5. **内容覆盖** — 检查主题是否有素材、素材是否有使用示例
6. **索引同步** — 确认索引与实际页面一致

### 工作流总览

```
 用户提供原始资料
        │
        ▼
    ┌─────────┐
    │  raw/   │  ← 范文、作文题、素材资料
    └────┬────┘
         │
         ▼
   /ingest（导入）
         │
         ├──→ wiki/material/    素材页面（原子化）
         ├──→ wiki/essay/       范文页面（原文 + 分析）
         ├──→ wiki/topic/       主题页面（自动创建/更新）
         ├──→ wiki/index.md     索引更新
         └──→ raw/archive/      原文归档
         
   /query（查询）  ← 用户提问 → 检索 wiki → 综合回答
   
   /lint（检查）   ← 定期运行 → 发现问题 → 修复链接/索引
```

### 使用教程

#### 前置要求

- [Obsidian](https://obsidian.md/) — 打开 vault 即可浏览 wiki
- [Claude Code](https://claude.ai/code) — 用于执行 `/ingest`、`/query`、`/lint` 操作
- [Obsidian CLI](https://github.com/coddingtonbear/obsidian-cli) — `/lint` 需要此工具检查链接（可选）
- Python 3.x — 运行 frontmatter 校验脚本（零依赖）

#### 快速开始

##### 1. 克隆项目

```bash
git clone <repo-url> EssaySystem
cd EssaySystem
```

##### 2. 在 Obsidian 中打开

用 Obsidian 打开 `EssaySystem` 文件夹作为 vault，即可浏览全部 wiki 内容。

##### 3. 导入素材

将范文或素材文件放入 `raw/` 目录，然后在 Claude Code 中执行：

```
/ingest
```

LLM 会自动处理 `raw/` 下所有未归档的文件。也可以指定文件：

```
/ingest raw/2024全国甲卷.md
```

##### 4. 查询内容

```
/query 有哪些关于坚持的素材？
/query 信息茧房主题下有什么范文？
/query 帮我推荐写命运共同体可以用的素材
```

##### 5. 健康检查

```
/lint
```

#### 手动操作

除 `/lint` 外，也可以直接运行 frontmatter 校验脚本：

```bash
python scripts/validate_frontmatter.py
```

输出示例：

```
ERROR: wiki/material/xxx.md - 缺少 type 字段
WARNING: wiki/topic/xxx.md - 主题文件名建议使用四字或六字短语
```

### 硬性约束

这些规则确保 wiki 的一致性和可信度：

| 约束 | 说明 |
|------|------|
| `raw/` 只读 | LLM 不得修改原始资料 |
| 范文全文不动 | 原文必须原样搬运，禁止任何改动 |
| 写作指导来自原始 | 禁止 AI 自行编写写作指导，必须来自 raw 资料 |
| 双向链接完整 | 所有关联使用 `[[双链]]`，A 引用 B 则 B 也引用 A |
| `log.md` append-only | 只追加不修改，保留完整操作记录 |
| 素材用本名 | 如 `苏轼.md`，不用 `宋代诗人苏轼.md` |
| AI 补充标注 `【AI】` | AI 用通用知识补充的内容必须标注来源前缀 |
| 矛盾走 `issues/` | 素材间事实冲突时创建问题报告，不擅自裁决 |

### 页面模板

#### 素材页面

```yaml
---
title: 苏轼
type: 素材
subtype: 人物
tags: []
---
```

包含：人物简介 → 关键事迹 → 使用示例（链接到具体范文）→ 关联素材

#### 范文页面

```yaml
---
title: 坦诚交流促相遇和谐相处共命运
type: 范文
from: 2024全国甲
tags: []
---
```

包含：题目 → 全文（原文不动）→ 结构分析 → 写作指导 → 关联素材 → 可学习之处

#### 主题页面

```yaml
---
title: 家国情怀
type: 主题
---
```

包含：主题分析 → 常见出题角度 → 关联素材 → 范文参考 → 审题关键词
